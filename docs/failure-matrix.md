# BhuVistaar — Operational Failure Modes & Recovery Matrix

This matrix documents 14 potential system, data, and network disruptions, specifying how BhuVistaar detects each condition, presents it to users, recovers safely, records audit trails, and protects data integrity.

---

| Failure Scenario | Detection Mechanism | User Notification / UI State | Recovery Procedure | Audit Behavior | Data Integrity Guarantee |
|---|---|---|---|---|---|
| **1. Database Unavailable** | Health probe `/health/ready` catches connection timeout. | System Readiness banner: `DATABASE: DISCONNECTED`. | Backend retries connection pool with exponential backoff; UI shows warning. | Logged in container stderr; audit resumes when DB reconnects. | Read-only mode enforced; zero writes permitted. |
| **2. PostGIS Extension Missing** | Health probe queries `postgis_full_version()`. | Readiness: `POSTGIS: MISSING`. | Run initialization script `CREATE EXTENSION postgis;`. | System startup blocker logged. | Spatial queries refuse execution without PostGIS. |
| **3. Frontend / Backend Disconnect** | Axios client network error interceptor. | Red header banner: `CONNECTION LOST — DISPLAYING LAST VERIFIED STATE`. | Automatic polling every 5s; state seamlessly refreshes upon reconnection. | Reconnection event logged in browser session. | No fabricated local updates; server remains authoritative. |
| **4. AI Model Unavailable** | AI endpoint returns HTTP 503 or `ai_mode = DISABLED`. | Readiness: `AI: FALLBACK / DISABLED`. Yellow badge in UI. | System falls back to deterministic heuristic candidate generation; workflow continues. | `AI_FALLBACK_ACTIVATED` event logged in audit table. | Spatial validation, review, and governance remain 100% operational. |
| **5. Corrupted Evidence Upload** | Pre-flight quality gate checksum & JSON parse check. | Evidence Quality: `BLOCKED` with specific syntax/parse error. | Ingestion rejected; surveyor prompted to re-export clean file from CAD. | `EVIDENCE_REJECTED` event logged with raw file hash. | Corrupt data never enters database tables. |
| **6. Duplicate Evidence Upload** | SHA-256 hash collision against `evidence_records`. | HTTP 409 Conflict: `DUPLICATE_EVIDENCE (Existing: ID-XXX)`. | Ingestion rejected; UI links directly to preexisting evidence record. | Duplicate attempt logged with IP/actor context. | No duplicate evidence records created. |
| **7. Conflicting Evidence Ingested** | Cross-source elevation comparison ($\Delta z > 0.10\text{m}$). | Evidence Panel: `EVIDENCE CONFLICT DETECTED`. | System flags anomaly; presents Side-by-Side Triad for human officer resolution. | `EVIDENCE_CONFLICT_DETECTED` event logged. | System never silently chooses one source over another. |
| **8. Stale Validation Run** | `ApprovalService` compares `val_run.created_at < revision.created_at`. | Gate C Eligibility: `VALIDATION_OUTDATED`. | Officer must re-trigger Gate A validation before Gate C approval is enabled. | `VALIDATION_MARKED_STALE` logged in audit trail. | Outdated validation can never be used to grant approval. |
| **9. Stale Evidence Checksum** | Provenance evidence hash $\ne$ current evidence table hash. | Gate C Eligibility: `STALE_EVIDENCE`. | Candidate marked stale; re-generation and re-validation required. | `EVIDENCE_MARKED_STALE` logged in audit trail. | Mutated evidence invalidates all dependent candidates. |
| **10. Missing Provenance Record** | `ApprovalService` finds zero linked provenance records. | Gate C Eligibility: `PROVENANCE_MISSING`. | Approval blocked; officer must re-bind candidates to source evidence files. | Blocker recorded in Gate C rejection reason. | Orphan cadastre cannot receive statutory approval. |
| **11. Self-Intersecting Polygon** | PostGIS `ST_IsValid(geom) = FALSE`. | Gate A Validation: `GEO-001 BLOCKER (Self-intersection)`. | Approval blocked; surveyor must correct polygon vertices in CAD/correction modal. | Validation blocker recorded in `validation_issues`. | Invalid 2D geometry cannot be extruded or approved. |
| **12. Human Reviewer Rejection** | Reviewing officer submits review decision == `REJECT`. | Candidate status updated to `REJECTED`; grayed out in viewer. | Unit is deactivated; predecessor revision remains active; workflow stops. | `REVIEW_SUBMITTED (REJECT)` logged with officer rationale. | Rejection is permanent; unit cannot be approved without a new revision. |
| **13. Export Serialization Failure** | Geometry or metadata unparseable during export. | HTTP 500: `EXPORT_FAILED` with correlation ID. | Error logged with correlation ID; fallback to raw GeoJSON FeatureCollection. | Error recorded in application logs with correlation ID. | Source database entities remain untouched and uncorrupted. |
| **14. Interrupted Field Upload** | Client connection drops midway through evidence transmission. | Ingestion status: `PARTIAL_INGESTION`. | Client resumes upload; server compares received SHA-256; completes record. | Resumption and completion logged in audit trail. | Incomplete uploads never trigger candidate generation. |
