# BhuVistaar — Antigravity Build Pack

Machine-assisted 3D cadastral prototype for SIH26011.

Core promise: convert a conventional 2D parcel into structured 3D spatial units, preserve the parent ULPIN linkage, attach evidence provenance, and automatically validate geometry/topology before human approval.

Non-negotiable:
- prototype only; not government-certified
- never replace or alter official ULPIN
- never call the prototype VUID an official 3D ULPIN
- AI generates candidates; deterministic validation and human review remain in control
- every output retains provenance

Recommended stack: React/TypeScript/Vite, CesiumJS, FastAPI/Pydantic, PostgreSQL/PostGIS, Shapely/GeoPandas/PyProj, Pytest/Hypothesis, Vitest/RTL, Playwright, Docker Compose.
