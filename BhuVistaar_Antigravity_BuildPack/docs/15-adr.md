# ADRs

ADR-001: Keep official ULPIN immutable and parent-only.
ADR-002: Use a clearly labelled prototype VUID rather than claiming an official 3D ULPIN.
ADR-003: Deterministic validation precedes ML.
ADR-004: PostgreSQL/PostGIS is the spatial system of record.
ADR-005: CesiumJS is visualization, not authority.
ADR-006: Local Docker Compose first; cloud later.
ADR-007: No LLM in the critical geometry path.
