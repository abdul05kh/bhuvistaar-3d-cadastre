# Acceptance Criteria

Functional:
- parcel import
- ULPIN preserved
- evidence linked
- 3D units generated
- deterministic VUID
- z ranges
- overlap/outside-parent/invalid geometry validation
- evidence visible
- human approval
- provenance-rich export

Technical:
- typed API
- PostGIS
- unit/property/integration/E2E tests
- build
- no secrets

Trust:
- no official-government impersonation
- no legal ownership inference
- no invented accuracy
- no undocumented transformations

Demo:
- clean startup
- resettable data
- reproducible defect
- reproducible export
