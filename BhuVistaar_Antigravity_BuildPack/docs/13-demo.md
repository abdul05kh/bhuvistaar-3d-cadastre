# Demo Script

1. Show 2D parcel + parent ULPIN.
2. Open evidence/provenance.
3. Generate 3D units.
4. Show floor volumes, basement, VUIDs and parent linkage.
5. Run validation.
6. Show deliberate overlap with rule code, measured value and affected unit.
7. Correct the interval.
8. Rerun validation and show pass.
9. Approve and show audit event.
10. Export JSON and show ULPIN, VUID, geometry, evidence, validation and audit metadata.

Judge-facing line:
"BhuVistaar does not merely render a 3D building; it creates traceable spatial units and tests their geometric/topological consistency before human approval."
